# ideas

まだ着手していないアイデアを ADR 風の連番 Markdown でためておく場所。

## 運用

- ファイル名: `NNNN-slug.md`（連番 + 内容がわかる短い英語スラッグ）
- 各ファイルの冒頭に Status と Date を書く
- Status のライフサイクル: `idea` → `experimenting` → `adopted` / `dropped`
- 採用して構成が固まったら、決定内容を README.md や CLAUDE.md 側に反映し、こちらは `adopted` にして経緯の記録として残す
